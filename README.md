# Trazo

Notas a mano, PDF y audio sincronizado para iPad, iPhone y Mac. Gratis.

- **Mac:** `./mac/build.sh` compila, instala `/Applications/Trazo.app` y la agrega al Dock.
- **iPad / iPhone:** publicar esta carpeta en HTTPS (p. ej. GitHub Pages), abrir en Safari › Compartir › Agregar a pantalla de inicio.
- **IA:** en el Mac usa tus sesiones de Codex (ChatGPT), Claude Code o Gemini CLI. En iPad/iPhone, una clave de OpenAI (GPT‑5 mini), Gemini o Claude en Ajustes › Inteligencia artificial.
- **Pasar notas entre equipos:** el Mac guarda copias automáticas en iCloud Drive › Trazo (`.trazobackup`); se importan desde Nueva › Importar.
